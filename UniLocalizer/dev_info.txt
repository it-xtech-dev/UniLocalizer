NuGet package publication:

1. Bump version in UniLocalizer.csproj (Version / AssemblyVersion / FileVersion).
2. From repo root, run:
     .\publish-nuget-packages.ps1
   The script shows current <Version> and asks you to confirm it was bumped when behavior/API meaning changed (Y = continue, N = cancel).
   Optional: -Configuration Debug, -FeedPath, or -SkipVersionConfirm to skip the prompt.
3. Packages are built to artifacts\nuget-packages\ and copied to \\nas-01\IT\Projekty\_NuGet_Storage

Consuming the package in other projects:
1. Add the NuGet feed (see ImPortal nuget.config or team docs).
2. Search for UniLocalizer.
3. Install or update.
