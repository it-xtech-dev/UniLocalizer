# UniLocalizer

ASP.NET Core localization with JSON (or SQL) storage, optional in-app translator, and JavaScript resource bundles.

**Package:** `UniLocalizer` (Razor class library)  
**Reference implementation:** ImPlatform.ImPortal (`wwwroot/locale`, `Extensions/LocalizerExtensions`, `Features/License/LicenseViolationFormatter`)

## Install

```xml
<ProjectReference Include="path\to\UniLocalizer\UniLocalizer.csproj" />
<!-- or NuGet when published -->
```

```csharp
// Startup.ConfigureServices
services.AddUniLocalizer(opt =>
{
    opt.ResourcesPath = Path.Combine(Directory.GetCurrentDirectory(), "wwwroot", "locale");
    opt.AutogenerateMissingKeys = true;      // dev: create #AUTOGENERATED tokens
    opt.IsTranslatorEnabled = false;         // production: disable /Localizer UI
    opt.JavascriptNamespace = "locale";    // window.locale in JS
});

// Startup.Configure (after UseRequestLocalization)
app.ApplicationServices.GetRequiredService<IStringLocalizerFactory>(); // warm-up optional
```

Register cultures with `services.Configure<RequestLocalizationOptions>(...)` and `app.UseRequestLocalization(...)`.

## Resource files (JSON)

Path under `ResourcesPath` maps to a **resource location** (dot-separated, lower case):

| File | Resource location |
|------|-------------------|
| `wwwroot/locale/pages/about.en-US.json` | `.pages.about` |
| `wwwroot/locale/implatform/importal/features/license/licensecontrolservice.pl-PL.json` | `.implatform.importal.features.license.licensecontrolservice` |

File name pattern: `{name}.{culture}.json` (culture = 5 chars, e.g. `en-US`).

JSON content: flat key → string:

```json
{
  "error_license_expired": "License expired.",
  "error_active_user_limit_exceeded": "Active users {0} exceed limit {1}."
}
```

Internal lookup key: `{culture}:{location}:{key}` (e.g. `pl-PL:.pages.about:title`).

## Usage scenarios

### 1. Razor / MVC — request culture (has `HttpContext`)

Uses `CultureInfo.CurrentUICulture` (set by `UseRequestLocalization`).

```cshtml
@inject IStringLocalizerFactory LocalizerFactory
@{
    var L = LocalizerFactory.Create(".pages.about");
}
<p>@L["welcome_title"]</p>
```

Or type-based location (`Create(typeof(AboutModel))` → `.full.type.name` lowercased).

```csharp
@inject IStringLocalizer<AboutModel> L
// requires IStringLocalizer registered; default UniLocalizer uses CurrentCulture at construction
```

### 2. Controller / service — explicit resource location

```csharp
public class AboutController : Controller
{
    private readonly IStringLocalizer _localizer;

    public AboutController(IStringLocalizerFactory factory)
    {
        _localizer = factory.Create(".pages.about");
    }

    public IActionResult Index() => View(_localizer["title"].Value);
}
```

Host extension (ImPortal):

```csharp
LocalizerExtensions.GetLc(factory, ".pages.about", "title");
// => ((UniLocalizerFactory)factory).Provider.Get(CultureInfo.CurrentUICulture, location, key)
```

### 3. Fixed culture — no `HttpContext` (background worker, startup, license evaluate)

**Do not** call `GetLc` with `CultureInfo.CurrentUICulture` on a thread pool thread — culture is often invariant or wrong, and there is no request.

**Pattern A — store keys only, translate at the boundary (recommended)**

ImPortal license evaluation:

```csharp
// LicenseControlService.Evaluate() — background / ctor, no HTTP
violations.Add(new LicenseViolationDetail("error_active_user_limit_exceeded", activeCount, limit));

// LicenseMiddleware / About page — has request culture
LicenseViolationFormatter.Format(factory, violation);
// uses CurrentUICulture via LocalizerExtensions.GetLc
```

**Pattern B — explicit culture via `UniLocalizerText`**

```csharp
var culture = new CultureInfo("pl-PL");
var text = UniLocalizerText.Get(factory, culture, ".implatform.importal.features.license.licensecontrolservice", "error_license_expired");
var formatted = string.Format(text, arg0, arg1);
```

**Pattern C — `UniLocalizer` with fixed culture**

```csharp
var factory = (UniLocalizerFactory)services.GetRequiredService<IStringLocalizerFactory>();
var loc = new UniLocalizer(factory.Provider, ".pages.about", new CultureInfo("en-US"));
var msg = loc["welcome_title"];
```

**Pattern D — `Provider.Get` directly**

```csharp
var factory = (UniLocalizerFactory)stringLocalizerFactory;
factory.Provider.Get(new CultureInfo("cs-CZ"), ".pages.shared", "app_name");
```

### 4. Default / fallback culture when user culture is unknown

```csharp
CultureInfo culture;
try
{
    culture = CultureInfo.GetCultureInfo(userCultureName);
}
catch (CultureNotFoundException)
{
    culture = CultureInfo.GetCultureInfo("en-US");
}

UniLocalizerText.Get(factory, culture, resourceLocation, key);
```

Configure the same default in `RequestLocalizationOptions.DefaultRequestCulture`.

### 5. JavaScript bundles

In Razor layout (requires `HttpContext`):

```cshtml
@Html.JsLocalizer("javascript.alert-demo", "pages.shared")
```

Serves cached script per culture; namespace from `ServiceOptions.JavascriptNamespace` (default `locale`).

### 6. Database-backed translations

```csharp
services.AddUniLocalizer(opt => { opt.ResourcesPath = "..."; }, connectionString: Configuration.GetConnectionString("Localizer"));
```

When `LocalizerDbContext` is registered, `SqlDbProvider` is used instead of `JsonProvider`.

### 7. Static access after pipeline startup (ImPortal)

```csharp
// Configure:
Program.LocalizerFactory = app.ApplicationServices.GetRequiredService<IStringLocalizerFactory>();

// Later (uses CurrentUICulture — only valid on request thread):
typeof(MyType).GetLc("some_key");  // location = .{type.FullName.ToLower()}
```

Prefer injecting `IStringLocalizerFactory` instead of statics in new code.

## API entry points

| Type | Use when |
|------|----------|
| `AddUniLocalizer` | Register services |
| `UniLocalizerFactory` | `Create(location)`, access `Provider` |
| `IStorageProvider.Get(culture, location, key)` | Full control, any thread |
| `UniLocalizerText.Get` | Explicit culture, no HttpContext |
| `UniLocalizer` | `IStringLocalizer` with optional fixed culture |
| `HtmlHelpers.JsLocalizer` | Client-side strings |

## IntelliSense

Build with `GenerateDocumentationFile` enabled; XML is emitted next to the assembly. Rebuild UniLocalizer after changes and reload the IDE.

## Translator (development)

Set `IsTranslatorEnabled = true` and browse `/Localizer` (Razor area). Missing keys can autogenerate as `#AUTOGENERATED` when `AutogenerateMissingKeys` is true. Disable in production.
